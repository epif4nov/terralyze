# TerraLyze

Веб-инструмент для анализа логов Terraform. Проект помогает инженерам быстрее разбирать сбои и долгие операции: подсвечивает ошибки и предупреждения, показывает JSON из строк лога и визуализирует последовательность операций.

> Текущий этап: аналитика и подготовка MVP. Рабочая реализация приложения ещё не добавлена.

## Зачем проект

Ручной разбор больших логов требует искать ошибки по ключевым словам и прокручивать много текста. JSON-вставки часто нечитаемы, а по сырому логу трудно понять последовательность и длительность действий. TerraLyze должен собрать эту диагностику в одном браузерном интерфейсе.

## Для кого

- DevOps-инженеры и инженеры поддержки (L1/L2), которые расследуют сбои Terraform `plan`/`apply`.
- Бизнес-аналитики, которым нужно понимать, где тратится время.

## Основной сценарий

1. Пользователь загружает текстовый лог Terraform.
2. Сервис потоково разбирает его на backend.
3. Интерфейс показывает сводку ошибок и предупреждений, строки лога, разобранные JSON-фрагменты и диаграмму операций.
4. Переход по проблеме или операции ведёт к соответствующей строке.

## Предполагаемый стек MVP

- Frontend: React + TypeScript.
- Backend и парсер: Go.
- Визуализация: Apache ECharts.
- Развёртывание: Docker и облачный хостинг.
