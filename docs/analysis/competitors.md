# Аналоги и конкуренты

Сравнение основано на проектном паспорте и требует актуальной проверки по документации и тарифам перед защитой.

| Категория / примеры | Что решают хорошо | Ограничения относительно TerraLyze |
|---|---|---|
| Текстовые редакторы и CLI: VS Code, Notepad++, `grep` | Доступны; локальная работа; быстрый поиск по тексту | Для Terraform-диагностики, дерева JSON и визуализации нужны отдельные инструменты или ручные действия |
| Сбор и анализ логов: Kibana, Grafana | Фильтрация и визуализация больших потоков событий | Обычно требуют настройки стека; ориентированы на мониторинг и рабочее окружение, а не на разовый анализ локального файла |
| Платформы Terraform: HCP Terraform, Spacelift, env0, Scalr | Управление запусками Terraform и совместной работой | Не предназначены для независимого разбора произвольного локального лога постфактум; нужен настроенный workflow |
| Специализированный CLI: `tf-profile` | Локальная статистика по ресурсам и диаграмма порядка операций | Нужна установка и работа в командной строке; в паспорте отмечено отсутствие единого UI с подсветкой ошибок и JSON-деревом |

## Проверяемое отличие

Гипотеза позиционирования: TerraLyze объединяет подсветку ошибок, просмотр JSON и временную диаграмму в браузере без установки. Перед заявлением «аналогов нет» нужно проверить актуальные продукты и подтвердить, что конкретные форматы Terraform-логов поддерживаются.

## Что проверить в конкурентном анализе

- Сравнить функции и ограничения на одинаковом тестовом логе.
- Проверить поддержку больших файлов и ограничения загрузки.
- Разделить прямые аналоги (например, `tf-profile`) и смежные категории.
- Уточнить, есть ли локальные браузерные инструменты с аналогичным набором функций.
